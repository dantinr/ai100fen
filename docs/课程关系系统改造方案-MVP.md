# AI100分课程关系系统改造方案（MVP）

## 文档目的

用于指导 Codex 对 AI100分项目进行课程体系升级。

目标：

在不重构完整学习图谱的情况下，先建立课程之间的关联能力，为未来 Z
助手推荐、学习路径和能力图谱扩展做准备。

------------------------------------------------------------------------

## 一、总体演进路线

未来：

课程 ↓ 课程关系 ↓ 课程标签 ↓ 能力模型 ↓ 个人能力图谱 ↓ Z Agent

当前阶段只实现：

课程 → 课程关系

------------------------------------------------------------------------

## 二、课程模型升级

courses 增加：

-   category
-   level
-   outcome
-   course_type

### category

枚举：

-   SOLVE：解决一个问题
-   CREATE：创作一个作品
-   EXPLORE：探索一个可能

### level

建议：

-   L0：体验课程
-   L1：基础能力
-   L2：独立完成
-   L3：复杂项目

### outcome

描述用户完成后的最终结果。

示例：

课程： 100分钟搭建网站

outcome：

用户拥有一个公网可访问的网站。

### course_type

枚举：

-   FREE_LAB
-   COURSE
-   MEMBERSHIP

------------------------------------------------------------------------

## 三、课程关系模型

新增数据表：

course_relations

字段：

-   id
-   course_id
-   related_course_id
-   relation_type
-   sort
-   description
-   created_at
-   updated_at

------------------------------------------------------------------------

## 四、关系类型

第一阶段只支持：

### prerequisite

前置课程

示例：

Linux基础 → 网站部署

### recommended

推荐课程

示例：

网站搭建 → SEO基础

### next

下一步课程

示例：

10分钟搭建网站 → 100分钟网站DIY

------------------------------------------------------------------------

## 五、后台管理

新增：

课程关联管理。

页面：

课程编辑页：

-   前置课程
-   推荐课程
-   下一步课程

支持添加、删除、排序。

------------------------------------------------------------------------

## 六、Free Lab 接入

免费课程作为入口节点。

示例：

FREE_LAB：

10分钟制作第一个网页

↓

COURSE：

100分钟搭建网站

不要复制内容，通过关系连接。

------------------------------------------------------------------------

## 七、Z 第一阶段能力

Z 暂不实现完整能力图谱。

第一阶段：

作为课程导航助手。

输入：

我想做一个网站

输出：

推荐路径：

1.  免费： 10分钟制作网页

2.  完整： 100分钟搭建网站

依据：

-   用户关键词
-   课程标签
-   课程关系

## 十、验收标准

完成后：

1.  管理员可以维护课程关系。
2.  用户可以看到课程路径。
3.  免费课程可以连接正式课程。
4.  Z 可以根据问题推荐课程。
5.  后续扩展能力图谱无需推翻数据库。

## 当前实施边界（2026-10-02，D-039）

上文为整体演进草案；用户已明确先实现“课程关系MVP”。实际第一阶段仅交付关系表、后台维护、独立排序、公开关系展示和数据库课程介绍页，不包含Z推荐及能力图谱。

复用现有CourseSeries表与小写category、final_outcome、is_free，不新增重复字段；level和course_type暂缓，MEMBERSHIP属于访问权益。关系外键采用course_series_id/related_course_series_id，排序采用sort_order，具体约束与公开边界以DECISIONS D-039、DATA_MODEL及docs/ADMIN.md为准。

前置只作建议，禁止自身、重复与前置循环；公开关系过滤草稿/归档，不自动发布课程。课程名称仍描述真实结果，Linux基础/SEO基础等知识型名称只是草案示例，不能作为正式课程终点。首阶段验收不要求Z推荐或承诺未来能力图谱永不调整数据库。
