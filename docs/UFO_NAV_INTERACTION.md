# AI100分 UFO_NAV_INTERACTION.md

## 问题池导航 UFO Hover 交互设计规范

------------------------------------------------------------------------

## 1. 功能目标

为顶部导航"问题池"增加 UFO 交互效果。

目标：

让用户第一次看到 AI100分 时感受到：

> 这里不是普通课程网站，而是一个会收集真实问题、帮助用户解决问题的 AI
> 系统。

------------------------------------------------------------------------

## 2. 交互对象

顶部导航：

``` text
首页
100分钟
问题池
直播
我的
```

其中：

``` text
问题池
```

绑定 UFO 交互。

------------------------------------------------------------------------

## 3. 默认状态

无操作：

-   UFO隐藏；
-   光束隐藏；
-   问题池正常显示。

------------------------------------------------------------------------

## 4. Hover状态

鼠标进入"问题池"：

``` text
          🛸
           |
           |
        扫描光束
           ↓

        问题池
```

触发：

1.  UFO出现；
2.  光束打开；
3.  问题池高亮。

------------------------------------------------------------------------

## 5. 动画流程

### 5.1 UFO出现

时间：

200ms - 300ms

动画：

``` css
opacity:
0 → 1

translateY:
-10px → 0
```

效果：

UFO从上方轻微进入。

避免：

-   快速飞入；
-   大幅旋转；
-   弹跳。

------------------------------------------------------------------------

### 5.2 UFO悬浮

持续 hover：

轻微上下浮动：

``` text
0px → -4px → 0px
```

周期：

2-3秒。

轻微左右摆动：

``` text
rotate:
-2deg → 2deg
```

------------------------------------------------------------------------

### 5.3 扫描光束

UFO稳定后显示光束。

动画：

``` text
opacity:
0 → 0.7

scaleY:
0.8 → 1
```

要求：

-   上窄下宽；
-   半透明；
-   柔和；
-   有扫描感。

------------------------------------------------------------------------

### 5.4 问题池高亮

文字状态：

默认：

``` text
问题池
```

Hover：

``` text
[ 问题池 ]
```

效果：

-   字体加粗；
-   颜色变化；
-   背景胶囊；
-   轻微强调。

------------------------------------------------------------------------

### UFO风格

采用：

-   Pop Art；
-   Retro Future；
-   Comic Style。

参考：

-   安迪·沃霍尔波普艺术；
-   50年代复古科幻海报；
-   漫画贴纸风。

避免：

-   蓝色赛博朋克；
-   企业AI大屏风；
-   玻璃拟态；
-   复杂3D模型。

## 11. 移动端策略

移动端没有 hover。

不能依赖 hover 完成功能。

方案：

### 点击触发

点击问题池：

``` text
UFO出现
↓
扫描
↓
进入问题池
```

或者：

直接关闭动画，只保留功能。

原则：

> 动画增强体验，不影响核心功能。

------------------------------------------------------------------------

## 12. 性能要求

``` text
SVG
+
CSS Animation
```

-   WebGL；
-   大型动画库。

要求：

-   不影响首屏加载；
-   不影响移动端性能。

## 16. 当前落地（2026-10-01）

- `resources/views/components/ufo-nav-link.blade.php`封装导航入口，复用`ufo-widget`图形，SVG和光束不接收鼠标事件。
- UFO主体约35px，位于文字上方，不改变导航尺寸；默认隐藏，桌面hover或focus-visible后250ms淡入并下移5px，光束300ms渐显。离开后淡出。
- 持续悬停的漂浮和光束呼吸周期2.8秒；进入、退出反馈保持250–300ms。复用现有黄橙黑与酸绿角色，文字用浅黄胶囊强调，尺寸和字重保持稳定。
- 手机、无hover和粗指针设备隐藏装饰；减少动态效果模式停止动画与过渡，保留静态UFO和文字提示。正常链接点击不等待动画。
- `/questions`仅显示筹备说明并引导浏览已有问题课程，问题池业务仍为P2；没有收集、保存或模拟用户问题。
