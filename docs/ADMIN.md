# AI100分管理台

路径：`/galaxy`。使用现有注册账号与原密码登录；仅显式授权的管理员可访问，开发环境也不放开普通用户。不提供默认管理员、默认密码或后台注册入口。

## 初始化

本地新增迁移已执行。其他环境先审阅新增迁移、备份目标数据库，再手动执行：

```sh
php artisan migrate --force --no-interaction
php artisan migrate:status
php artisan admin:set 已注册邮箱
```

授权命令询问确认，输入yes才会生效；账号不存在时不会自动创建。撤销使用`php artisan admin:set 已注册邮箱 --revoke`。线上用dante运行，`git pull` Hook不自动迁移或授予权限；不修改.env或已有密码。

## 创建并发布课程

“课程基本信息”中的“课程标签 / 关键词”按回车逐个添加，可移除后保存。已发布课程的首页和列表卡片显示标签，搜索也可匹配；为空时使用主要类别说明，草稿不公开。复用原推荐关键词，Z免费任务推荐继续使用同一字段，标签不替代Solve/Create/Explore主要类别。

课程基本信息可上传16:9横向封面（建议1600×900，JPG/PNG/WebP，最大2 MB），可在编辑页裁切或移除。已发布课程更换封面后立即显示；未上传或文件缺失时保留原有海报。封面只存公开图片路径，不影响课程状态、课时权限或进度。课程管理列表会显示缩略图，前台首页、100分钟目录、免费任务列表使用同一封面比例。`/series`介绍页封面显示课程目标及成果清单，使用已有最终成果与完成标准；所有已发布课程读取后台最终成果，所有课程读取数据库公开介绍。上传封面仍用于课程卡片及播放器回退画面。

封面文件放在`storage/app/public/course-covers`，不进入Git。首次使用前以项目用户运行`php artisan storage:link`，确认`public/storage`指向该目录；生产新增字段须审阅`2026_10_02_200000_add_course_series_cover.php`并独立迁移。日常git pull Hook不会自动迁移或创建链接，详见`deploy/README.md`。

本地首次初始化同样需要执行`php artisan storage:link`；Windows会建立从`public/storage`到`storage/app/public`的目录联接，该映射被Git忽略，不随源码检出自动建立。若上传成功但图片无法显示，依次检查文件是否存在、公开映射是否有效，以及`APP_URL/storage/course-covers/文件名`是否返回HTTP 200；已有文件只需恢复映射，无需重新上传。

课程列表显示课程ID，操作列“课时管理”进入对应课程的课时列表；可更换或清除“所属课程”筛选。当前筛选课程下创建课时会预选该课程。编辑页下方的大纲仍用于查看与排序课时。

课程和课时编辑页的“保存/取消”操作栏在长表单滚动时固定于视口底部，可直接保存当前修改；原操作区进入视口后回到原位。桌面与手机均使用Filament原生行为。

课时编辑的“课时目标清单”逐项填写这一课要得到的成果；学习页右侧显示为“目标1、目标2、目标3”等编号清单，手机在正文开头展示。未填写时只显示已有“本课要做成什么”，不会自动编造目标。侧栏同时提供本课验收进度与入口，整门课程大纲及总进度在内容下方；管理员预览显示相同目标，但不保存学习进度。

课时创建/编辑页的“视频播放器”区可单独设置播放器封面：上传JPG、PNG或WebP（最大2 MB），支持16:9裁剪，建议1600×900。保存后在课时学习页与管理员前台预览的播放前画面显示；未上传或文件缺失时使用课程封面，本地演示再回退默认演示图。更换时先移除原图再上传，移除后恢复默认；操作只移除字段引用，不删除原文件，也不改变课程状态或已保存验收。文件位于`storage/app/public/lesson-video-posters`，复用现有`public/storage`公开映射；没有视频且未开启本地演示时不显示播放器。

本地已执行新增可空字段迁移`2026_10_05_010000_add_lesson_video_poster.php`；线上须由运维审阅后独立执行，常规pull Hook仍不迁移。后台“视频地址”须为HTTPS直连HLS/MP4媒体地址，不能填写一般观看网页；播放器配置见`docs/PLAYER.md`。

操作列“前台预览”在新标签页打开当前主题的学习页面，可以查看草稿、已发布或归档课程、付费课程及未发布课时。没有课时时显示课程信息与添加入口。通过路线切换课时，返回课程编辑继续修改。预览只读取已保存内容，访客须登录、普通账号拒绝访问；不发布课程、不保存验收进度、不开放资料下载，不替代真实付费用户的访问规则。页面设置private/no-store缓存策略（D-035）。

1. 在“课程管理”创建草稿，填写描述真实结果的名称、英文地址标识，以及唯一Solve/Create/Explore类别。
2. 填写课程介绍、目标、预计时长，明确用户意图、最终成果、整个任务验收标准、Agent职责与人的判断事项。草稿可以逐步完善；发布前六项必填。
3. 保存后进入编辑页，下方“课程大纲”添加课时。每个课时填写顺序、目标、步骤大纲、Prompt与验收，必要时添加Markdown正文、代码、HTTPS视频链接或文本资料。
4. 至少发布一个内容完整的课时，其余课时可保留草稿；单节课仍须补齐目标、步骤、Prompt与验收。
5. 课程定义完整且至少一个课时已发布，就可将课程设为“已发布”；课数与时长按真实任务调整，不再填写累计分值或凑满100。开启“整门课程完整免费”后全部已发布课时自动免费，课时编辑隐藏单课试看开关；付费课程可单独配置“免费试看”。全部当前课时发布后进入免费实验室，最后一步仍需按课程完成标准由人核对真实结果。当前付费固定100元、整门免费0元，后台编辑不发放支付权限（D-057）。

课程大纲来源于关联课时，不重复保存另一套数据；课时的steps是本课大纲。可拖动调整课程课时顺序，操作前清除表格筛选并显示全部未归档课时；调整后检查课时顺序与最终验收。

新增课时、调整课时状态或顺序会使已发布课程回到草稿，重新审核并发布后才恢复前台访问。归档保留内容与学习记录；D-050提供课程删除/回收站，D-055增加课时批量软删除/回收站。已有进度的验收项不可直接改写，需先设计内容版本迁移，不用清空用户记录绕过限制。

## 课时多选与批量操作（D-055）

在“课时管理”列表勾选多行，或全选当前页，点击工具栏的“批量发布”或“批量删除”，核对确认弹窗后执行。批量发布逐课校验目标、步骤、Prompt与验收，不绕过编辑页的内容规则；已发布课时不重复改变状态，不自动发布整门课程。任一课时不合格、选择失效或所属课程已删除时整批不改动，保留勾选并提示原因，刷新或补齐内容后再试。

批量删除将课时软删除至“课时回收站”页签，保留ID、内容与上传文件；有任何学习记录（包括未完成、0%）的课时会阻止整批删除，请保留或归档。回收站可多选后“批量恢复”，课时恢复为草稿；被删除的所属课程需先在课程回收站恢复。不提供课时最终删除，删除状态与归档状态不同。列表、大纲、课时计数、完整免费筛选、进度分母及旧试看不显示已删除课时。

发布/删除/恢复导致课时结构或状态变化后，所属课程回到草稿。先核对课时目标与顺序，发布课时，再在“课程管理”审核并重新发布课程。完整免费实验室须所有当前课时发布，不再要求分值合计100。

## 课程展示排序

课程列表显示“展示排序”，操作列点击“设置排序”，输入数值并点击“保存排序”，成功后显示确认消息；编辑课程的基本信息中也可设置。输入0–999999的整数，数字越小越靠前，默认1000。比如将三门课设为10、20、30即可确定先后。列表默认按展示排序升序；点击表头仅改变后台查看顺序，不改变保存的数值。

也可点击列表工具栏的上下箭头进入拖动模式，按行拖动课程调整展示位置，再点击勾号结束。拖动会立即保存全体课程的顺序，并重排为连续的1、2、3……；搜索或筛选期间不能保存部分课程的全局顺序，请先清除条件。需要指定数值或保留编号间隔时，继续使用“设置排序”。

课程管理和课时管理的列表表格超出可见宽度时，表格上方也会显示横向滚动条，与底部滚动位置双向同步；无需先滚动到列表底部才能查看右侧操作。复用同一滚动条视图，窗口缩放、筛选或分页导致表格更新时自动重新计算宽度；没有横向溢出时隐藏，不影响编辑页面或其他后台页面。

排序保存后，刷新首页、课程目录或免费实验室即可看到新顺序；都按后台sort_order升序，同值按ID升序。仅已发布课程进入公开目录，草稿调整标题、关键词、封面或排序不会公开。

展示排序属于课程之间的展示位置，与课时“大纲顺序”不同；仅修改展示排序不会让课程退回草稿，不影响价格、内容访问、学习进度或验收。

上线此次功能需审阅并独立执行新增迁移`2026_10_02_140000_add_course_series_sort_order`（新增默认1000的列及索引），先备份课程相关数据，再运行`php artisan migrate --path=database/migrations/2026_10_02_140000_add_course_series_sort_order.php --force --no-interaction`。日常git pull Hook不自动迁移，不执行rollback删除已保存的排序。

## 直播管理（D-044）

在`/galaxy/live-sessions`创建场次，填写主题、北京时间开始/结束、状态与简介。草稿不出现在`/live`；保存为“已排期”后公开展示。状态改为“直播中”需提供HTTPS课堂入口，此时访客可通过站内受控链接进入；改为“可看回放”需提供HTTPS回放链接，历史回放区同步出现。取消或回放整理中都不开放课堂入口。删除功能未开放，改为“已取消”保留场次记录。

## 课程关系（D-039）

编辑课程，在页面底部切换“课程关系”页签，点击“添加课程关联”。选择关系类型与目标课程，填写关联理由（可选）和关系内排序，保存即可。编辑关联可调整目标、类型、理由和排序；“移除关联”须确认，只移除连接，不删除课程、课时或进度。

- 前置课程：建议先完成所选目标课程，不强制锁学习。
- 推荐课程：与当前目标相关的另一个任务。
- 下一步课程：当前任务做成后，可以继续完成的任务。

三类均为单向关系，不自动反向连接。数字越小越靠前，默认1000，同值按关联ID升序；它不改变首页展示排序和课时大纲顺序。不能关联自身，同一类型不能重复；前置不能形成直接或间接循环。

可以提前关联草稿或归档目标。管理员前台预览显示全部连接，并跳转到受保护预览。公开免费学习页和`/courses/{slug}`课程介绍仅展示已发布且有已发布课时的源/目标；完整免费还须全部未归档课时发布。原`/series/{slug}`详情只在同slug数据库课程已发布时展示其关系，默认使用原目录展示内容；D-051网站完整免费课程保留该页面结构并读取数据库公开大纲。

因此，旧课程仍为草稿时，免费任务关联它们不会立即出现在公开页面。完成内容编排并按宪章发布后才可见，不能靠关联绕过发布。数据库介绍页只公开介绍、大纲与验收；付费课时正文/Prompt/代码/附件仍不开放，购买暂未实现。

新增表需独立审阅后运行`php artisan migrate --path=database/migrations/2026_10_02_160000_create_course_relations_table.php --force --no-interaction`。git pull Hook不迁移，不安装示例关系。level、标签及Z关系推荐后置。

## 删除课程与回收站（D-050）

回收站显示删除时间，可“恢复课程”：确认后恢复为草稿，课时、资料与原学习记录保留，审核并重新发布后才开放前台。回收站中不提供编辑、排序或前台预览。
