# AI100分 · 分享学习成果给好友

| 项目 | 说明 |
|---|---|
| 功能名称 | 分享学习成果给好友 |
| 状态 | 待做 |
| 建档日期 | 2026-10-04 |
| 入口 | 任务完成页、我的成果列表；具体位置以现有源码为准 |
| 目标 | 学员展示自己做成的作品或解决的问题，好友可以查看并找到对应学习入口 |
| 实施边界 | 当前为功能需求文档，网站尚未修改 |

## 一、分享什么？

围绕学员实际完成的任务生成分享内容，突出三个信息：

- 我完成了什么任务。
- 我做出了什么作品，或解决了什么问题。
- 好友可以从哪里开始尝试。

完成状态来自任务的真实验收记录。若当前系统只有学员自行确认，应注明“学员自行验收”，不能包装为平台认证。观看课时、点击按钮或经过100分钟不能自动等同于成果验收通过。

## 二、操作流程

1. 学员进入已完成任务的结果页，点击“分享我的成果”。
2. 预览分享卡片，选择是否公开作品截图、作品地址和显示名称。
3. 确认公开范围，创建分享链接。
4. 复制链接或保存卡片图片，由学员自行发给好友。
5. 好友无需登录即可查看被授权公开的成果，点击进入对应课程或免费任务。

页面不自动发送消息，不读取通讯录。浏览器支持系统分享时可提供入口；不支持时使用复制链接与保存图片。

## 三、成果卡片

### 基本内容

| 内容 | 要求 |
|---|---|
| 品牌 | AI100分，沿用现有Logo与主题 |
| 任务名称 | 来自实际任务或课程，例如“100分钟搭建一个 .com 网站” |
| 成果描述 | 一句具体说明，学员可编辑，例如“我的第一个网站已经上线” |
| 完成状态 | 与真实任务状态一致，说明验收方式 |
| 成果截图 | 可选，由学员预览并确认公开 |
| 作品地址 | 可选，仅分享学员明确选择公开的地址 |
| 显示名称 | 可选，不默认公开真实姓名、邮箱或账号标识 |
| 分享入口 | 指向本站成果分享页；图片可包含相同地址的二维码 |

默认分享任务名称、成果描述与验收方式。其他信息由学员主动选择。

### 示例文案

> 我用人与Agent协作，搭建了自己的第一个网站。  
> 已完成：域名访问、HTTPS、内容更新与备份恢复。  
> 你也可以从一个免费小任务开始。

示例中的完成项目必须按该学员真实验收结果生成，不能给每张卡片固定套用同一份清单。

### 视觉

- Pop主题沿用奶油色、荧光绿、黄色、粗黑描边与硬阴影。
- 主视觉突出成果标题或作品截图；Z可以作为小型祝贺元素。
- 网页预览复用主题变量；保存的图片保证文字、截图和品牌清楚可读。
- 图片建议优先制作适合聊天查看的竖版卡片，具体尺寸由实测确定。
- 不默认展示排行榜、课程用时、经验值或虚构评分。

## 四、好友看到的分享页

- 无需登录即可查看已发布的分享内容。
- 显示任务、成果描述、验收方式，以及学员选择公开的附加内容。
- 有公开作品地址时展示“看看这个作品”；没有时隐藏该按钮。
- 提供“我也想做一个”入口，连接实际课程；若课程未开放，明确说明状态。
- 提供“从免费任务开始”入口，复用现有免费实验室。
- 手机优先保证截图、标题、操作按钮和长地址可读。
- 不向好友公开学员任务后台、聊天记录、文件目录、笔记或其他未选择的内容。

## 五、公开范围与撤销

- 分享页由专门的公开数据生成，不能直接暴露私有任务详情接口。
- 分享地址使用难以枚举的标识，不使用连续用户ID作为公开访问凭据。
- 学员可以查看已有分享、编辑公开字段和撤销链接。
- 撤销后原链接不再返回成果详情，展示“该成果分享已取消”。
- 处理分享页、图片和接口缓存，避免撤销后仍可从原公开资源地址读取内容。
- 默认分享页不进入搜索索引；不纳入公开站点地图。
- 分享链接并非访问控制凭据；需要登录的作品仍按作品本身的权限访问，不因分享自动变为公开。
- 发布前提示：“持有链接的人可以查看你选择公开的内容。请检查截图和作品地址中的个人信息。”
- 撤销能停止本站继续展示，无法收回好友已经保存的图片或复制的内容。

## 六、实施范围

先完成最小版本：成果预览、选择公开字段、创建链接、复制链接、保存图片、好友查看、撤销分享。

优先复用现有任务状态、验收记录、用户权限、主题组件和课程链接。若这些数据尚未完整实现，先补齐所需最小记录，不伪造完成状态。

卡片图片可由同一份分享数据生成，保证文字与页面一致。二维码指向真实分享页，生成失败时报告错误，不能使用装饰性二维码。

不新增积分奖励、好友邀请返利、通讯录导入或自动群发。不为了保存截图而擅自访问需要授权的站点，作品截图使用学员提供或已有权限范围内的素材。

## 七、验收

- [ ] 未完成或无验收记录的任务不能冒充已完成成果。
- [ ] 预览、图片与分享页的内容一致。
- [ ] 自行验收与平台核验有明确区别。
- [ ] 默认不公开姓名、邮箱、聊天、私有笔记或其他任务数据。
- [ ] 未登录好友能够查看有效分享，无法访问其他私有记录。
- [ ] 复制链接、保存图片正常；二维码可以打开对应分享页。
- [ ] 作品及课程按钮链接真实可用，权限和开放状态表达正确。
- [ ] 分享者可以撤销，原链接及受控资源不再返回成果内容。
- [ ] 非分享者不能编辑或撤销该分享。
- [ ] 手机预览及打开体验正常，长标题、截图和地址不溢出。
- [ ] 分享页默认不被索引，响应与页面配置沿用项目的禁止索引方式。
- [ ] Z名称正确，主题一致，没有自动发消息操作。

## 八、交给开发Codex的指令
