# AI100分

别再学 AI 了，先用 AI 把一件事做成。

## 项目简介

AI100分帮助用户使用 AI / Agent **解决一个问题、创作一个作品、探索一个可能**。标准课程由10个约10分钟的步骤组成；每10分代表完成一个可见步骤，100分代表得到可验收的真实结果。

当前为 **Laravel / Blade 前台 MVP 预览**，采用 Tailwind CSS、Vite 与 SVG 图标。目录包含16个课程方向，网站系列第一课可免费试看，其余内容逐步完善。

已实现：

- 首页、课程目录、筛选搜索与系列详情。
- 第一课图文学习、Prompt / 代码复制、验收清单下载及本机学习记录。
- 邮箱注册、登录、记住登录与退出；个人中心支持修改昵称和密码。
- `/free`免费实验室：个人介绍网页、CSV汇总、Prompt对照实验三个完整任务；访客直接学习，登录保存验收进度。
- `/galaxy` Filament管理台：管理员管理数据库课程、课时目标与大纲、内容及发布状态；配置全站Pop/Future主题。
- 单门课程100元、订阅299元/月的说明页；当前不收取费用。
- 响应式页面、UFO导航与进度动效、全站主题配置；默认Pop，Future为验证骨架。
- 提交记录页面，使用每日方块墙展示真实Git更新，支持按日查看和分页。
- 问题池话题标签墙，浏览AI/Agent关注问题与尝试的第一步，附参考来源及轻量动效。
- Paul原创外星向导，提供四种表情和意图快捷入口，可收起或暂时隐藏。

支付、真实订阅、视频上传与付费课程账号进度尚未接入；16个旧课程方向已导入后台为草稿，公共目录仍待切换数据库。问题提交与直播仍在筹备，邮箱找回密码待邮件服务配置。
