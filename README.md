# AI100分

别再学 AI 了，先用 AI 把一件事做成。

## 项目简介

AI100分帮助用户使用 AI / Agent **解决一个问题、创作一个作品、探索一个可能**。课程由可验收的步骤组成，课数与时长可按任务调整；完成百分比按当前课时数均分，100%代表全部步骤及真实成果已验收。

当前为 **Laravel / Blade 前台 MVP 预览**，采用 Tailwind CSS、Vite 与 SVG 图标。前台课程以后台数据库设置为准，只展示已发布课程；旧课程方向保留在后台草稿中逐步完善。

已实现：

- 首页、课程目录、筛选搜索与系列详情。
- `/about`关于AI100分：项目定位、实践方向、发起原因与维护者介绍，顶部导航提供固定入口。
- 图文学习、Prompt / 代码复制、资料下载与账号验收记录；课程进度按当前课时数动态计算。
- 邮箱注册、登录、记住登录与退出；个人中心支持修改昵称和密码。
- `/lab`免费实验室：个人介绍网页、CSV汇总、Prompt对照实验等完整免费任务；访客直接学习，登录保存验收进度。
- `/galaxy` Filament管理台：管理员管理数据库课程、课时目标与大纲、内容及发布状态；配置全站Pop/Future主题。
- `/live`直播日历与手机场次列表；后台可管理公开直播排期、入口及回放，暂无正式场次时显示示例日程。
- 单门课程100元、订阅299元/月的说明页；当前不收取费用。
- 响应式页面、UFO导航与进度动效、全站主题配置；默认Pop，Future为验证骨架。
- 提交记录页面，使用每日方块墙展示真实Git更新，支持按日查看和分页。
- 问题池话题标签墙，浏览AI/Agent关注问题与尝试的第一步，附参考来源及轻量动效。
- 问题黑洞与Z规则工作台：整理任务卡，确认后私人保存，提供本人查看和真实成功动效。
- Z原创外星向导，提供四种表情和意图快捷入口，可收起或暂时隐藏。

支付、真实订阅、视频上传与付费课程账号进度尚未接入；公共课程目录已切换数据库，旧课程方向需完善并发布后展示。直播目前仅支持公开场次，会员/课程专属访问待接入；邮箱找回密码待邮件服务配置。
